# Evidence Images

**Current status: screenshots have not been added.**

Use the same identifiers as the graph exports. For example, the screenshot for graph `03-01` can be named `03-01-try-interact.png`.

Capture the graph entry, decisive condition and visible result. Split a wide graph into numbered crops instead of making all node labels unreadable. A full graph can accompany the close crops when it helps with context.

Also capture actual timeline curves, relevant variable types/defaults, component or collision settings, UMG layout/animations, and a small in-game result where they are needed to explain the code.

Only use evidence from the current project build. Portfolio diagram redraws should be identified as explanatory diagrams rather than source screenshots.
